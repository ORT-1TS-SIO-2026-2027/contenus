# TP 1 - Premiers Pas en JavaScript

**Durée :** 4 heures  
**Objectifs :** Consolider les bases du JavaScript et développer vos compétences en résolution de problèmes

## Consignes Générales

- Créez un fichier HTML nommé `tp1.html` qui contiendra tout votre code JavaScript
- Utilisez la console du navigateur pour afficher vos résultats avec `console.log()`
- Commentez votre code pour expliquer votre démarche
- Respectez las conventions de nommage (camelCase)
- Testez chaque exercice avant de passer au suivant

## Structure HTML de Base

```html
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>TP 1 - JavaScript</title>
</head>
<body>
    <h1>TP 1 : Premiers Pas en JavaScript</h1>
    <p>Ouvrez la console (F12) pour voir les résultats</p>
    
    <script>
        // Votre code JavaScript ici
    </script>
    // ou
    <script src="index.js"></script>
</body>
</html>
```

## Partie 4 : Logique Combinée (45 minutes)

### Exercice 4.1 : Conditions d'Accès
Un utilisateur peut accéder à un service si :
- Il est majeur (âge >= 18) ET il a un compte actif (`compteActif = true`)
- OU il est mineur mais accompagné d'un adulte (`accompagne = true`)

Créez des variables pour tester différents cas et affichez "Accès autorisé" ou "Accès refusé".

Testez ces combinaisons :
- âge = 16, compteActif = false, accompagne = true
- âge = 20, compteActif = true, accompagne = false  
- âge = 17, compteActif = false, accompagne = false

### Exercice 4.2 : Calcul de Remise
Un magasin applique des remises selon ces règles :
- 10% si montant >= 100€
- 5% supplémentaires si le client est fidèle (`clientFidele = true`)
- 2% supplémentaires si c'est un achat en ligne (`achatEnLigne = true`)

Créez un programme qui :
- Calcule le montant final après remises
- Affiche le détail des remises appliquées
- Teste avec : montant = 150, clientFidele = true, achatEnLigne = false

### Exercice 4.3 : Validation de Formulaire
Simulez la validation d'un formulaire d'inscription avec :
- `nom` : ne doit pas être vide
- `email` : doit contenir "@" (utilisez `.includes("@")`)
- `age` : doit être entre 16 et 100 ans
- `conditions` : doit être accepté (`true`)

Créez des variables avec des valeurs de test et affichez "Formulaire valide" seulement si tous les critères sont respectés, sinon affichez les erreurs spécifiques.

## Partie 5 : Projet Intégrateur (30 minutes)

### Exercice 5.1 : Simulateur de Crédit
Créez un simulateur qui calcule les mensualités d'un crédit avec ces données :
- `montantCredit` : 20000€
- `tauxAnnuel` : 3.5% (à convertir en taux mensuel)
- `dureeAnnees` : 5 ans (à convertir en mois)

Formule de calcul des mensualités :
```
mensualite = (montant × tauxMensuel) / (1 - (1 + tauxMensuel)^(-nombreMois))
```

Le programme doit :
- Calculer le taux mensuel : `tauxMensuel = tauxAnnuel / 100 / 12`
- Calculer le nombre de mois : `nombreMois = dureeAnnees × 12`
- Calculer la mensualité avec la formule
- Calculer le coût total du crédit
- Calculer le coût des intérêts
- Afficher un récapitulatif complet

### Bonus : Conditions du Crédit
Ajoutez des vérifications :
- Le montant doit être entre 1000€ et 500000€
- La durée doit être entre 1 et 30 ans
- Le taux doit être entre 0.5% et 15%
- Affichez des messages d'erreur appropriés si les conditions ne sont pas respectées
